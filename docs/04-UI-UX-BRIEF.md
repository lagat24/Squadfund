# 4. UI/UX Design Brief

## Direction
Calm, precise, trustworthy. The memorable element is the **progress ruler**: a thin horizontal bar with gold milestone ticks. Everything else stays quiet: flat surfaces, hairline borders, left-aligned text.

## Palette
- Paper `#F2F5F4`, surface `#FFFFFF`
- Petrol (primary) `#0F3A45`, darker `#0A2A32`, mid `#236677`
- Text `#15272C`, muted `#4F656B`, line `#D3DDDE`
- Gold accent `#B88A1E` (text-safe `#8E6812`), used only for: logo mark, milestone ticks and reached markers, the savings figure on offers, the active nav marker.
- Danger `#A5392A`, ok `#2F6F4F`

## Type
Headings and large figures: Bricolage Grotesque. Body and UI: Public Sans. Tabular numerals for money. Sentence case; no all-caps labels.

## Layout
Left-aligned. Group pages use a narrow left nav on desktop and a scrolling row on mobile. Dashboard: main column (progress, members, milestones) and a side column (your plan, invite code, rules). No three-column feature grids.

## Components
Radius 4 to 6px. 1px borders, no default shadows. Icons from Icons8 Line Awesome. Loading uses skeleton blocks. Errors say what happened and what to do. Simulated and Sandbox items carry a visible "Simulated" or "Sandbox" tag and a notice.

## Avoid
Gradients, glassmorphism, heavy shadows, rounded-2xl everywhere, emojis in UI, Lottie, confetti, hover-scale, centered spinners, promotional copy, fake testimonials or stats.

## Accessibility
Visible focus rings, labelled inputs, status never by colour alone, reduced motion respected, responsive to 360px.
